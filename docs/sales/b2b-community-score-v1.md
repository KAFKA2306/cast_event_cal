# B2B Community Score v1

VRChatイベント観測データから、企業案件で実際に接触しやすいコミュニティを優先順位付けするための販売用スコア。

## 目的

イベント件数ではなく「企業が次に動けるか」を評価する。スコアは営業先の自動決定ではなく、PoC納品時の調査優先順位に使う。

## スコア（100点）

| 軸 | 点 | 判定 |
| --- | ---: | --- |
| 公開接触窓口 | 25 | Discord / VRChat Group / 公式フォーム等の公開窓口が確認できる |
| 企業・団体との実績 | 25 | 企業登壇、協賛、後援、共同企画等の公開実績がある |
| 参加型導線 | 20 | LT募集、登壇募集、出展募集、企画持込等の公開導線がある |
| 継続性 | 15 | 観測期間内に複数回開催、または公式に定期開催を確認できる |
| 外部展開 | 10 | リアルイベント、カンファレンス、他コミュニティ等との連携実績がある |
| テーマ一致 | 5 | 対象企業の製品・採用職種・業界と明示的に一致する |

各軸は根拠URLまたは観測event IDを必須とする。根拠が確認できない場合は0点。推測で加点しない。

## ランク

- A: 80–100。PoCの上位候補として提示
- B: 60–79。追加確認後に提示
- C: 40–59。補欠候補
- D: 0–39。営業候補から除外

## 現在の5候補への適用方針

前回までに調査した ITインフラ集会 / VRChat.rb / ML集会 / ゲーム開発集会Ⅳ / VRChat.ts を最初の校正セットにする。

ITインフラ集会は公開窓口、LT導線、企業所属エンジニアの登壇、外部イベント連携が確認済みのため、Aランク候補。残る4件は同じ軸で根拠を埋め、点数が確定するまで順位を固定しない。

## PoCで返す列

community_name, score, rank, fit_reason, contact_url, participation_url, corporate_evidence_url, recurrence_evidence, external_evidence_url, next_event, observed_occurrences

## ガードレール

- 「観測回数」と「累計開催回数」を混同しない。
- 次回開催日は納品生成時点で再計算する。
- category欠損を文字列部分一致だけで自動分類しない。
- 公開窓口があっても、営業・協賛受付を意味するとは断定しない。
- 個人情報や非公開連絡先は収集しない。
